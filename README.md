# Lane Widget 4×2

Минималистичный виджет-плеер: тёмная карточка, розовый акцент, обложка, название, исполнитель,
полоса прогресса и кнопки назад / играть / вперёд. Работает с Lane и с любым плеером,
который показывает системное медиауведомление.

## Как собрать APK

### Вариант 1. GitHub (без установки чего-либо)
1. Создай пустой репозиторий на github.com.
2. Загрузи туда все файлы из этой папки (включая скрытую `.github`).
3. Вкладка **Actions** → **Build APK** → дождись зелёной галочки (3–5 минут).
4. Внутри запуска скачай артефакт `lane-widget-apk`, распакуй, получишь `app-debug.apk`.

### Вариант 2. Android Studio
Открой папку как проект, дождись синхронизации и нажми **Build → Build APK(s)**.

## Установка
1. Поставь APK (разреши установку из неизвестных источников).
2. Открой Lane Widget → **Выдать доступ** → включи переключатель для приложения.
3. Долгое нажатие на рабочем столе → Виджеты → Lane Widget → растяни до 4×2.

На Xiaomi/HyperOS включи для Lane Widget автозапуск и режим «Без ограничений» в настройках батареи,
иначе система может усыплять сервис, и виджет перестанет обновляться.

## Цвета
Все цвета в `app/src/main/java/app/lanewidget/Palette.kt`.
Размеры (обложка 84dp, радиус карточки 30dp) в `LaneWidget.kt`.

Скругление углов карточки работает на Android 12 и новее.

## Чтобы виджет не засыпал
На экране Lane Widget есть блок «Чтобы виджет не засыпал»: кнопка снятия ограничений батареи и кнопка
автозапуска (на Xiaomi открывает нужный экран). Плюс приложение держит тихое уведомление
«Lane Widget работает»: это служба переднего плана, она не даёт системе убить процесс.
Уведомление можно свернуть в настройках уведомлений, служба при этом продолжит работать.

## Какие плееры показываются
Видеосервисы и браузеры игнорируются. Список по умолчанию в `Blocklist.kt`, а на экране
Lane Widget любой плеер можно скрыть или вернуть вручную.

## Частота обновления полоски
`TICK_MS` в `MediaListener.kt` (по умолчанию 1000 мс). Таймер работает только пока играет музыка и включён экран.


## Кнопки виджета 4×2
Верхний ряд: назад, играть/пауза, вперёд, «нравится» (плюс, а если трек уже любимый, то галочка;
нажатие на галочку убирает трек из любимых). Нижний ряд: перемешать (под «назад»), повтор
(под «вперёд»), скачать для офлайна (под «нравится»). Серый значок: плеер этого не умеет.

Перемешать и повтор работают через `MediaControllerCompat` (библиотека androidx.media), «нравится»
и «скачать» ищут дополнительное действие плеера по названию. Что именно отдаёт плеер, видно на
экране «Диагностика».

## Компактный виджет 4×1
Отдельный виджет в списке виджетов: обложка, название, исполнитель, тонкая полоска и кнопка play.

## Обновление поверх старой версии
APK подписывается постоянным ключом `app/lane.keystore`, поэтому новую версию можно ставить
поверх старой без удаления. Разрешения (доступ к уведомлениям, батарея) при этом сохраняются.
`versionCode` берётся из номера запуска сборки на GitHub Actions и растёт сам.
Ключ лежит в репозитории специально: приложение личное. Если репозиторий публичный и это
беспокоит, ключ можно перенести в GitHub Secrets.

## Сборка и релизы
Каждая сборка на GitHub Actions подписывается ключом из секретов репозитория (KEYSTORE_BASE64,
KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD), номер версии равен номеру запуска, APK публикуется
в Releases как v<номер>. Ключа в репозитории нет.

## Самообновление
Кнопка «Проверить обновление» на главном экране берёт последний релиз, сравнивает номер сборки
и, если он новее, скачивает APK и открывает установщик. Первый раз Android попросит разрешить
установку для Lane Widget.
