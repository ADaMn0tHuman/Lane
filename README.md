# Lane Widget

Виджет для Android с управлением музыкой из любого плеера, в приоритете Lane. Показывает обложку, название, полоску прогресса и кнопки управления, поддерживает два размера, оформление и обновления прямо из приложения.

## Установка и первый запуск

1. Скачайте APK из раздела **Releases** в репозитории и установите.
2. Откройте **Lane Widget**.
3. Нажмите **«Выдать доступ к уведомлениям»** и включите Lane Widget в списке. Без этого доступа виджет не видит плееры.
4. Разрешите уведомления, если приложение спросит.
5. Добавьте виджет на экран: долгое нажатие на пустое место рабочего стола → **Виджеты** → **Lane Widget**. Доступны два размера: большой 4×2 и компактный 4×1.

Если виджет показывает «Выдай доступ к уведомлениям», значит доступ не выдан. Нажмите на виджет, откроется приложение.

## Виджеты

| | Большой (4×2) | Компактный (4×1) |
|---|---|---|
| Обложка | да | да |
| Название и исполнитель | да | да |
| Полоска с временем | да | полоска без времени |
| Кнопки | назад, play, вперёд, лайк, перемешать, цикл, скачать | только play |
| Своё фото на фон | да | да |

Фон (обложка, размытие, своё фото, прозрачность) общий для обоих виджетов.

**Нажатие на виджет** открывает плеер, который сейчас играет. Если экран плеера недоступен, открывается его приложение.

## Кнопки виджета

В **«Внешний вид → Кнопки виджета»** каждую кнопку можно убрать и вернуть отдельно:

- лайк (плюс, а для любимого трека галочка; нажатие на галочку убирает трек из любимых),
- скачать (для офлайна),
- цикл (выключен → весь список → один трек),
- перемешать,
- значок смены плеера,
- назад и вперёд.

Кнопка **«играть»** всегда на месте. Скрытая кнопка оставляет пустое место, остальные не сдвигаются.

**Назад и вперёд на паузе:** трек не запускается. «Назад» перематывает в начало, если трек идёт дольше 3 секунд, иначе переходит к предыдущему. «Вперёд» переходит к началу следующего трека.

**Конец трека:** если трек закончился, виджет остаётся на конце трека (например, `4:32 из 4:32`) на паузе.

**Значок плеера** под обложкой показывает приложение, которое играет. Нажатие переключает плеер: текущий ставится на паузу, следующий начинает играть.

## Оформление

### Цветовые паки

Пакет задаёт три цвета: фон карточки, акцент (кнопки, полоска, исполнитель) и текст. Точка на полоске может быть своего цвета, иначе она такая же, как текст.

- **Тёмная** и **Светлая** встроены и не удаляются.
- **Свой пак:** введите название и цвета в формате `#RRGGBB`. Справа от полей показан предпросмотр карточки.
- **Экспорт и импорт пака одной строкой:** `Название: #фон #акцент #текст` или `Название: #фон #акцент #текст #точка`. Строку можно скопировать и отправить другому человеку.

**Оформление:**
- **Акцент из обложки:** цвет кнопок и полоски берётся из обложки.
- **Фон из обложки:** обложка становится фоном карточки. Размытие настраивается от 0 (резко) до 100 %.
- **Авто тёмная или светлая:** пак выбирается по системной теме телефона.

### Фон виджета

- **Фон из обложки** и **размытие** (см. выше).
- **Своё фото на фон.** Выберите картинку, она обрежется под размер 4×2 без растягивания. Настраиваются приближение и сдвиг по горизонтали и вертикали. Для лучшего результата берите горизонтальные фото.
- **Прозрачность цвета фона.** Работает только для сплошного цвета пака, когда нет обложки и фото: цвет становится полупрозрачным, и просвечивают обои.

### Полоска и время

- **Показывать оставшееся время:** справа вместо общей длительности, например `-1:12` вместо `4:10`.
- Полоска прогресса показывает текущую позицию точкой.

## Плееры

Виджет управляет любым плеером, который показывает уведомление с элементами управления.

**Скрыты по умолчанию:** YouTube и его сборки, ВКонтакте, TikTok, Instagram, Netflix, Twitch, Rutube, Кинопоиск, видеоплееры, галереи и браузеры. Так виджет не подхватывает видео.

Чтобы показать или скрыть любой плеер, откройте **«Плееры»** и нажмите на его название. Ручной выбор важнее списка по умолчанию.

Если играют несколько плееров, виджет выбирает тот, который играет, а при равенстве предпочитает Lane.

## Работа в фоне

Чтобы виджет не отключался, системе нужно разрешить ему работать в фоне.

1. В разделе **«Работа в фоне»** нажмите **«Не ограничивать батарею»** и подтвердите.
2. Нажмите **«Автозапуск и фоновая работа»** и включите Lane Widget в настройках вашей прошивки (Xiaomi, Huawei, Oppo, Vivo и других).
3. Проверьте статус службы: должна быть строка «Фоновая служба: работает».

Приложение держит тихое уведомление «Lane Widget работает». Его можно свернуть в настройках уведомлений, работа от этого не остановится.

**Экономный режим** (в разделе «Энергия и обновления»): полоска обновляется раз в 2 секунды вместо 1. Расходует меньше батареи, движение менее плавное.

## Обновления

- **Проверка по кнопке:** в разделе «Обновления и диагностика» нажмите **«Проверить обновление»**. Если вышла новая версия, приложение скачает APK и откроет установщик.
- **Автоматически раз в 12 часов:** если вышла новая версия, придёт уведомление.
- **Первая установка обновления:** Android попросит разрешить установку для Lane Widget. Включите и нажмите кнопку ещё раз.
- **Обновление поверх старой версии** ставится без удаления: все настройки и разрешения сохраняются.

Установщик не откроется, если подпись скачанного APK не совпадает с установленной, и вы увидите сообщение об этом.

## Настройки: экспорт, импорт, сброс

В разделе **«Энергия и обновления → Настройки»**:

- **Экспорт настроек в файл.** Сохраняет все паки, переключатели, фон и своё фото в один JSON-файл.
- **Импорт настроек из файла.** Заменяет текущие настройки на сохранённые.
- **Сбросить все настройки.** Удаляет паки, переключатели и фото. Перед сбросом появляется подтверждение, отменить его нельзя.

Экспорт полезен, чтобы перенести настройки на новый телефон или после переустановки.

## Частые вопросы

**Виджет пустой или показывает «Выдай доступ к уведомлениям».**
Включите доступ к уведомлениям для Lane Widget в настройках (см. «Установка»).

**Кнопки или обложка не меняются, после нажатия задержка.**
Проверьте раздел «Работа в фоне». Если ограничение батареи включено, система может усыплять виджет. Сделайте шаги из раздела.

**Виджет показывает не тот плеер.**
Откройте «Плееры» и скройте лишние приложения. Или выключите видеосервисы, которые там появились.

**Цвет пака не применяется сразу.**
Нажмите на пак ещё раз. Если не помогло, откройте диагностику и пришлите её текст разработчику.

**Не работает «Скачать».**
Кнопка работает, только если плеер сам её поддерживает. Если кнопка серая, плеер её не отдаёт.

**Не нашёл нужную настройку.**
Все настройки разбиты по группам: «Работа в фоне», «Внешний вид», «Плееры», «Энергия и обновления». Нажмите на заголовок группы, чтобы раскрыть или свернуть её.

## Для разработчика

- **Сборка:** GitHub Actions собирает APK при каждом push. Номер версии равен номеру запуска (`versionCode`).
- **Подпись:** APK подписывается ключом из секретов репозитория (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`). Ключа в репозитории нет.
- **Релизы:** каждая сборка публикуется в Releases как `v<номер>`. Хранятся последние 5, остальные удаляются автоматически.
- **Проверка обновлений:** приложение читает страницу последнего релиза, а не API GitHub, чтобы не упираться в лимит запросов.
- **Диагностика:** экран «Диагностика» показывает состояние службы, выбранный плеер, его действия и последнее нажатие на виджет. Текст можно скопировать.

Лицензия и условия использования: уточните у автора репозитория.
